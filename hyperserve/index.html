HyperServe

A Go server library built on net/http. You keep your standard handlers and routes. HyperServe adds middleware, typed input, readiness and graceful shutdown, with Server-Sent Events, WebSocket and MCP when you need them.

Canary Desk and Canary CLI both run their HTTP servers on it. It is MIT-licensed, with one dependency outside the standard library. If your service only needs routes and JSON, plain net/http is usually the better choice.
